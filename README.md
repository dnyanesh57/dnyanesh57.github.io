# Dnyanesh Nikam — Portfolio

Personal portfolio site: structural engineering, BIM automation, construction data science and project controls.

## Publish on GitHub Pages

1. Create a public repository named **`<your-github-username>.github.io`**.
2. Upload `index.html`, `README.md` and `.nojekyll` to the root of the repository.
3. Go to **Settings → Pages**, set *Source* to **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
4. After a minute the site is live at `https://<your-github-username>.github.io`.

## Editing

- **Projects**: edit the `PROJECTS` array near the bottom of `index.html` — each entry has a category (`bim`, `data`, `structures`, `planning`, `quality`), title, description, bullet points and tags.
- **Experience / credentials**: edit the HTML sections with the same names.
- Add images later by putting them in an `assets/` folder and referencing them as `assets/filename.jpg`.
